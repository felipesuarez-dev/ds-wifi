Ayuda · conectar una DS
Guía de conexión
  1. Inserta un juego con WFC (Mario Kart DS, etc.) → NINTENDO WFC → Nintendo WFC Settings.
  2. Para la MAC: Options → System Information. El Nintendo WFC ID es la MAC (12 caracteres).
  3. Agrega esa MAC aquí en Configuración → Acceso (con los dos puntos).
  4. Enciende la red con el botón.
  5. En la DS: Ajustes de conexión → Buscar punto de acceso → elige el SSID (sin candado).
  6. Cambiar ajustes → DNS manual:
Primario: 178.62.43.212
Secundario: 1.1.1.1
178.62.43.212 es Kaeru (rutea a Wiimmfi). Algunos juegos con SSL necesitan el parche NoSSL.
